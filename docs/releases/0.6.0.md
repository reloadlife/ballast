# Ballast 0.6.0 — Health

Ballast now helps you inspect storage health and Mac security alongside disk cleanup. Open **Health** in the sidebar, even before your first disk scan.

- **Drive health:** read-only SMART status for physical drives, with SSD endurance used, spare capacity and cumulative media errors where macOS exposes them. Startup disk space is flagged below 10% free. Unavailable readings are never reported as healthy.
- **Mac security:** check FileVault, System Integrity Protection, Gatekeeper and the application firewall. Open System Settings to review protections or check macOS updates. Ballast does not change settings.
- **Known package vulnerabilities:** review installed Homebrew core formula versions locally, then explicitly choose to check them against OSV advisories. Every installed revision is included. Matches link to advisory details; failed or incomplete requests never become clean results.
- **Private by default:** package review reads installation receipts without running Homebrew or refreshing metadata. Each online check separately asks before sending the reviewed names and versions to OSV, which also receives your IP address. Disk health data, file paths, receipts and app inventory stay local.
- **Native navigation:** Health is available from the sidebar, Shortcuts and `ballast://health`.

Vulnerability coverage is limited to stable Homebrew core formulae in `/opt/homebrew` and `/usr/local`. Mac apps, casks, third-party taps, custom prefixes, HEAD builds and other package managers are not covered. No known matches is not a security guarantee. SMART cannot predict every failure; maintain a current backup. Ballast does not provide malware protection or run automatic repairs.

The README and website now explain the new checks, their limits and their privacy controls.
